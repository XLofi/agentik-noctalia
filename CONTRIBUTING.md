# Contributing to Agentik for Noctalia

Agentik is an MIT-licensed project with maintainer-led development. Issues and pull requests are welcome; maintainers decide which changes fit the product direction, when they merge, and when releases ship.

Contributions must preserve the local-first security model, OMP journal single-writer rules, accessibility settings, and Thinking Orbs attribution in `THIRD_PARTY_LICENSES`. Do not submit customer code, credentials, signing keys, private release artifacts, or dependencies with incompatible or unknown provenance.

Before contributing, confirm that you own the change or have authority to contribute it under MIT-compatible terms. Run the release gates listed in `ROADMAP.md`.

Report security issues through [SECURITY.md](SECURITY.md), not a public issue.
